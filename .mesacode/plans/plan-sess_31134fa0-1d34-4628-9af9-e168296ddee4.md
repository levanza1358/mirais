## YouTube fetching untuk music library (Invidious multi-instance, stream-only)

### Tujuan
User bisa menambahkan trek dari YouTube ke music library lewat search + import di dashboard. Backend berbicara ke instance Invidious publik/self-hosted untuk metadata + audio URL (mode `source_type='url'`). Tidak ada download; audio di-stream langsung dari Invidious oleh browser melalui tag `<audio>`.

### Area yang disentuh

#### Backend (Bun + Elysia)
1. **`src/config.ts`** — tambah env schema `INV_INSTANCES` (JSON array URL) dan `INV_TIMEOUT_MS`. Default: parse dari `process.env.INV_INSTANCES` (comma-separated atau JSON). Empty → kosong. Validasi zod: `z.array(z.string().url()).min(1).max(20)` jika ada.
2. **`src/utils/invidious.ts`** (baru) — klien tipis:
   - `pickInstance()` — round-robin / failover dari array. Track last-success per instance in-memory + probe ulang kalau gagal. Gunakan `AbortSignal.timeout(invTimeoutMs)`.
   - `invidiousFetch(path)` — fetch dengan fallback ke instance lain bila 5xx/timeout. Throw `AdminError(503, "All Invidious instances unreachable")` bila semua gagal.
   - `parseVideoSummary(video)` → `MusicTrack`-compatible shape (id, title, authorId→artist, lengthSeconds→duration_sec, adaptiveFormats untuk audio URL).
   - `pickAudioUrl(video)` → dari `adaptiveFormats[]` cari entry `type=audio/mp4` atau `audio/webm` (codec `mp4a.40.2` atau `opus`) dengan container yg cocok, prefer highest bitrate < 160k. Field disimpan sebagai `source_url`.
   - `searchVideos(q, page=1)` → array `VideoSummary[]`.
   - `getVideo(id)` → `VideoSummary`.
3. **`src/shared/schemas.ts`** — `youtubeSearchQuerySchema` (q string, page?), `youtubeImportSchema` (`{ video_id: string | url: string, playlist_id?: string }`).
4. **`src/admin/music.ts`** — tambah 3 endpoint di bawah prefix `/api/music/youtube`:
   - `GET /youtube/search?q=...&page=...` — proxy ke Invidious, kembalikan list minimal (id, title, author, lengthSeconds, thumbnail).
   - `GET /youtube/suggestions?q=...` — autocomplete. (Bisa `null` jika Invidious tak mendukungnya.)
   - `POST /youtube/import` body `{ video_id | url, playlist_id? }` — resolve URL→video_id (regex YouTube ID), panggil `getVideo`, `pickAudioUrl`, create `MusicTrack` lewat repo, audit `youtube_import`. Tambah `video_id` ke playlist jika diberi.
   - Route-file difaktorkan agar testable: `musicRoutes(db)` masih me-mount prefix `/api/music`; `youtubeRoutes(db, settings)` me-mount di bawah prefix yang sama.
5. **`src/admin/settings.ts`** — `GET /api/settings` expose `invidious` block (instances, last healthy index), `PATCH` izinkan operator update instance list.
6. **`src/admin/auth.ts`** — `/api/music/*` sudah publik, jadi endpoint baru otomatis publik.

#### Frontend (React + TanStack Query)
1. **`dashboard/src/api.ts`** — extend `music` namespace: `youtubeSearch(q)`, `youtubeSuggestions(q)`, `youtubeImport({ video_id })`. Tambah type `YouTubeVideo` (id, title, author, lengthSeconds, thumbnail).
2. **`dashboard/src/components/music/AddFromYouTubeDialog.tsx`** (baru) — modal di halaman Music dengan search input + debounced suggestions (300ms) + result list (thumbnail + title + author + duration) + tombol "Add to library" (atau "Add to playlist" bila playlist dipilih). Pakai pola autocomplete yang sudah ada (`CommandPalette.tsx` di dashboard/src/components sebagai referensi debouncing).
3. **`dashboard/src/pages/Music.tsx`** — tombol "Add from YouTube" di toolbar; modal ini muncul saat diklik. Track baru dari import akan muncul otomatis karena invalidate `["music-tracks"]`.
4. **`dashboard/src/pages/Settings.tsx`** — tambah sub-section di tab Music untuk konfigurasi instance Invidious (list URL + tombol "Add" + status terakhir) + tombol "Test connection".

#### Audio playback & CORS
- Direct URL dari Invidious (`/latest_version?id=...&itag=...`) memakai CORS permissive untuk browser (`Access-Control-Allow-Origin: *`). Tag `<audio>` di MiniPlayer/NowPlaying akan fetch langsung.
- Karena URL Invidious expire (beberapa jam), track `source_url` diperbarui setiap kali user "Add from YouTube". Tidak ada refresh otomatis background untuk MVP.
- Test di environment yang tidak punya Invidious: import akan gagal dengan 503 yang ditampilkan ke user sebagai toast error.

#### Tests (`test/`)

### Pertimbangan keamanan & privasi
- Invidious instance URL disimpan di settings (audit trail via `PATCH /api/settings`).
- Setiap track import disimpan dengan `source_url` eksplisit, bukan auto-redirect, sehingga user tahu audio link-nya siapa.
- YouTube video ID tidak boleh dipanjang lebih dari 11 char (regex validator).
- Rate-limit sederhana: cache `youtubeSuggestions` di FE (debounce + 1 query per 300ms).
